Connect trained weights

Local file integration steps

  1. Place your model fileCopy your trained `.pt` weights into the project's `models/` folder.
  2. Set the model pathUpdate `AEGIS_MODEL_PATH` in your environment configuration.
  3. Match hazard class namesSet `AEGIS_HAZARD_LABELS` to the exact class names produced by your trained model.
  4. Install AI dependenciesRun pip install ultralytics, then restart the app.
Important

A generic object-detection model is not automatically a hazard detector. Use a model trained and evaluated on the safety categories you need.
